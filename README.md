## Features

- **Crystal Clear Sound:** Real-time 48,000 Hz, 16-bit PCM dual-mic stereo streaming over local Wi-Fi.
- **Low Latency:** 5ms frame pacing with adaptive jitter buffer and packet loss concealment.
- **Accessibility:** Full support for Google TalkBack (Android) and NVDA / JAWS / Windows Narrator (Windows).
- **100% Privacy:** Audio travels strictly across your local network. No accounts, no advertising, no tracking.
